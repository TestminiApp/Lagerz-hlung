Artikelverwaltung

Artikel bleiben dauerhaft gespeichert. Bei Wochenwechsel nur die 5–10 Änderungen vornehmen. Deaktivierte Artikel verschwinden aus künftigen Zähllisten; ältere Ergebnisse bleiben erhalten.

Artikel bearbeiten

Historie

Abgeschlossene und laufende Zähltage. Frühere Tagesbestände bleiben erhalten.

Datensicherung

Die Daten werden in diesem Browser auf diesem Gerät gespeichert. Sie werden nicht an einen Server übertragen.

Wichtig auf dem iPhone: Regelmäßig eine Sicherungsdatei exportieren. Das Löschen von Safari-Website-Daten, privates Surfen oder ein Gerätewechsel können lokale Daten entfernen. Für eine dauerhafte Nutzung empfiehlt sich später eine Installation über eine HTTPS-Adresse.

Hinweise

Jeder Tag wird unabhängig gezählt. Mehrere Erfassungen pro Artikel werden summiert. Ein Artikel gilt erst als erledigt, wenn eine Zählposition erfasst oder Nullbestand bestätigt wurde. Artikelnummern sind getrennte Bestände, auch bei ähnlicher Bezeichnung. Bei einem Artikelwechsel bleiben vergangene Zähltage unverändert.
